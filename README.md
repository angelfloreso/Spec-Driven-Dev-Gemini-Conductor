# Demo Project for Spec-Driven Development with Gemini CLI

## Practices Overview

- P1 - The Immutable Build: learn spec-first development where OpenAPI is the source of truth and build/test gates prevent contract drift.
- P2 - OpenAPI Generator: generate Spring interfaces and models from OpenAPI YAML, then implement against generated contracts.
- P3 - Reverse Engineering: extract OpenAPI contracts from existing Spring Boot code using `springdoc-openapi` and enrich quality with annotations.
- P4 - NL Specs: turn natural-language requirements into a validated OpenAPI YAML contract with an AI-assisted workflow.
- P5 - Integrating Legacy Systems: apply consumer-driven contracts to legacy integration so producer changes are caught in CI.
- P6 - Gemini Conductor: run guided AI implementation workflows on a full-stack sample project and validate backend/frontend changes.
